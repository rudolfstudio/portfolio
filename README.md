# Portfólio — Pablo Rudolf

Site: https://rudolfstudio.github.io/portfolio/

Portfólio em Next.js, React e TypeScript. O fluxo de publicação importa o código e as imagens dos arquivos source.part* na primeira execução e mantém os arquivos do projeto diretamente neste repositório.

Depois da importação, os projetos ficam em src/data/projects.json e as imagens em public/media/. A ordem de Design de posts é definida em src/lib/portfolio-categories.ts. Capas: 2000 × 1000 px. O carrossel mantém o formato original de cada post.

As artes, fotografias e marcas pertencem aos seus respectivos titulares. A disponibilidade pública deste repositório não concede licença de reutilização.
